# NEXORA: Typography (V1)

| Use | Font | Weights | Source |
|---|---|---|---|
| Headlines | Space Grotesk | Bold, SemiBold | Google Fonts |
| Body text | Inter | Regular, Medium, SemiBold | Google Fonts |

## License
Both fonts use the SIL Open Font License (OFL):
free for commercial use. License files are included in each font folder.

## German characters
Both fonts support ä ö ü ß Ä Ö Ü.
Test line: Größe, Lösung, Straße, Prüfung, Ärger

## Rules
- Headlines: Space Grotesk Bold, short (max 3 lines).
- Body: Inter Regular or Medium.
- Use at most 2 fonts per cover or video.
- Install the fonts on the editing computer before opening projects.

## Fallback
If a font is missing: Arial for body text, Montserrat for headlines.
