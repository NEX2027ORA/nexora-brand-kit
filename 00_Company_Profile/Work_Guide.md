# دليل العمل والأدوات

## أدواتنا

| الأداة | الاستخدام |
|---|---|
| GitHub | حفظ الملفات والوثائق وتنظيم العمل المشترك وتوثيق التغييرات |
| ClickUp | جدولة المهام وتوزيعها ومتابعة حالتها |
| Google Drive | حفظ ملفات الفيديو الكبيرة (لا تُرفع على GitHub) |
| Instagram | نشر الريلز التي تعرض محتوانا وخدماتنا |

## قواعد العمل على GitHub
1. لا نعدّل على الفرع `main` مباشرة. ننشئ فرعاً لكل عمل جديد.
2. نفتح Pull Request ويراجعه عضو آخر قبل الدمج.
3. نكتب رسالة الـ commit بالعربية واضحة ومختصرة، مثل: `تحديث ألوان الشعار`.
4. نحدّث حالة العمل في الملفات (علامات ✅) فقط عند الإنجاز الفعلي.

## تسمية الملفات
- بالإنجليزية وبلا مسافات.
- النمط: `NEXORA_<الأصل>_<الرقم>_v<الإصدار>.<الامتداد>`
- مثال: `NEXORA_Highlight_01_v1.png`

## ClickUp: حالات المهمة المقترحة
`للتنفيذ` ← `قيد العمل` ← `قيد المراجعة` ← `منجزة`

لكل مهمة: مسؤول واحد، وتاريخ تسليم، ووصف واضح.

## ريلز إنستغرام وGoogle Drive
- ترفع ملفات الفيديو على Google Drive، ويُسجَّل **رابطها فقط** في المستودع.
- هيكل المجلدات المقترح على Drive:
  - `Reels/` ثم مجلد لكل شهر (مثل `2026-12`)
  - `Covers/` أغلفة الريلز
  - `Raw/` اللقطات الخام
- جدول تتبّع الريلز (ملف `Reels_Log.md` نضيفه لاحقاً): التاريخ، الموضوع، المسؤول، رابط Drive، الحالة.

## قبل النشر
- [ ] النص بالألمانية الفصحى وبلا أخطاء إملائية.
- [ ] الأغلفة والألوان والخطوط مطابقة للهوية.
- [ ] مراجعة عضو آخر.
