## الفئات المطلوبة

1. **حسابات تقنية ألمانية:** كيف تخاطب جمهوراً ألمانياً وبأي مستوى من الرسمية.
2. **أغلفة الريلز:** تنظيم العنوان والرقم والمساحات الفارغة.
3. **الألوان والخلفيات الداكنة:** درجات الأزرق الداكن مع لمسة منت أو سماوي.
4. **الطباعة:** العناوين البسيطة الحديثة المشابهة لـ Space Grotesk.
5. **الحركة:** بدايات الريلز ونهاياتها وأسلوب ظهور النص.
