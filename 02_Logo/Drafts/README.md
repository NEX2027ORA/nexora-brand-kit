# مسودات الشعار

هذا المجلد للتجارب والأفكار والنسخ القديمة وغير المعتمدة.

## القواعد
- التسمية: `NEXORA_Draft_<الرقم>_v<الإصدار>.png` بحروف إنجليزية وبلا مسافات.
- لا تُستخدم هذه الملفات في أي منشور أو ريل.
- عند اعتماد نسخة، تُصدَّر نظيفة بالاسم الصحيح إلى `Final`.
- تُحذف النسخ المكررة والمرفوضة بين فترة وأخرى للحفاظ على النظافة.
