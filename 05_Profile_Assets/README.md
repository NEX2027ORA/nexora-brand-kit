
# أصول الملف الشخصي (Profile Assets)

هذا المجلد مخصص لأصول واجهة حساب إنستغرام الخاص بـ NEXORA.

## محتويات المجلد

| الملف | الوصف | المقاس |
|---|---|---|
| `NEXORA_Profile_Picture_v1.png` | الصورة الشخصية (أيقونة Network X على خلفية Midnight Navy) | 1080×1080 |
| `NEXORA_Highlight_01_v1.png` إلى `NEXORA_Highlight_05_v1.png` | أغلفة الـ Highlights الخمسة | 1080×1920 |

## قواعد التصميم

- الخلفية: Midnight Navy (`#0B1120`) أو أي لون من اللوحة المعتمدة في `03_Colors`.
- الأيقونة: Network X وحدها بدون اسم NEXORA، بنسخة Icon_Color أو Icon_White.
- الأيقونة في المنتصف، فإنستغرام يقصّ الصورة على شكل دائرة.
- الألوان تؤخذ من `brand-tokens.json` فقط.
- التسمية: إنجليزي، بلا مسافات، بالنمط `NEXORA_<الأصل>_<الرقم>_v<الإصدار>.png`.
