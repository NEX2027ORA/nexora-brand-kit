# الاسم والنبرة

وثائق قرار الاسم ونبرة الصوت (Tone of Voice) الخاصة بعلامة NEXORA.

## المحتويات
- `NEXORA_Name_Decision_V1.md`: قرار اسم الشركة وفحوصاته وحالة الموافقة.
- `NEXORA_Tone_and_Vibe_V1.md`: شخصية العلامة ولغتها وأسلوب مخاطبة الجمهور.

## ملاحظة
المحتوى الموجّه للجمهور الألماني (الشعارات النصية واسم الحساب) يبقى بالألمانية،
وبجانبه معناه بالعربية للفريق.
